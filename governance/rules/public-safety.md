# Public Safety Rule

Public workflow repositories must not include:

- credentials or token values
- private logs or chat transcripts
- internal hostnames or VPN-only URLs
- personal phone numbers or email addresses
- customer, employer, or partner data
- local machine state that cannot be reproduced

Use examples such as:

- `user@example.com`
- `https://example.com`
- `/path/to/project`
- `TOKEN_VALUE_HERE`
