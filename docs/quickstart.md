# Quickstart

Use A-Team as a reference toolkit. Copy only the workflows you need.

## Recommended Path

1. Read `llms.txt`.
2. Pick one workflow from `.claude/commands`.
3. Adapt paths and done criteria to your project.
4. Add a project-local `AGENTS.md`.
5. Run the workflow with your AI assistant.

## First Commands To Try

- `vibe.md`: session start
- `pickup.md`: resume work
- `review.md`: code review
- `tdd.md`: implementation loop
- `end.md`: closeout

## Adaptation Checklist

- Replace local paths with your project paths.
- Remove organization-specific assumptions.
- Define test commands for your stack.
- Define ownership boundaries for the agent.
- Keep one source of truth for current state.
